### KONDISI PROJECT SAAT INI

Fitur berikut SUDAH BERHASIL dan WAJIB dipertahankan:

1. `MainActivity` transparan.
2. Window tidak menerima touch sehingga aplikasi tetap dapat digunakan untuk interaksi layar normal.
3. `MainActivity` menjalankan `PrankAudioService` menggunakan `startForegroundService()`.
4. `MainActivity` kemudian menjalankan `finishAndRemoveTask()`.
5. Aplikasi tidak muncul sebagai kartu di Recent Apps.
6. `PrankAudioService` berjalan sebagai Foreground Service.
7. Service berada pada process terpisah `:prank_service`.
8. `stopWithTask="false"`.
9. Audio dapat looping.
10. Volume dapat dinaikkan ke maksimum dan nilai awal dapat dipulihkan.
11. Notification Foreground Service memiliki action untuk menghentikan service.
12. Force Stop melalui Settings/ADB dapat menghentikan aplikasi.
13. Build menggunakan Gradle CLI dan saat ini berhasil `BUILD SUCCESSFUL`.

### LAUNCHER / VISIBILITY REQUIREMENT

Periksa konfigurasi launcher application.

Bedakan dengan jelas antara:

* menghapus Activity dari Recent Apps;
* menutup Activity;
* aplikasi tetap terpasang;
* aplikasi tetap dapat ditemukan dan dihentikan melalui mekanisme sistem;
* dan perubahan visibility launcher.

`finishAndRemoveTask()` **tidak boleh dianggap sebagai fitur hide launcher**.

Jika requirement visibility launcher belum dapat dipenuhi tanpa membuat aplikasi menjadi sulit ditemukan/dihentikan pengguna, **jangan mengimplementasikan mekanisme stealth persistence**.

Pertahankan aplikasi tetap dapat dikelola melalui Android Settings dan mekanisme sistem.
